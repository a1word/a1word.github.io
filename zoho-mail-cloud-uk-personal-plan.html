Zoho Mail Cloud UK Personal Plan

21 November 2026

Just to be clear from the outset, this is purely for the free PERSONAL plan only - you still can use an own domain with the personal plan, but at extra cost.


The zohomailcloud.co.uk domain became available for UK customers to register in mid-2026, which coincided with the launch of Zoho’s UK data centres in London and Manchester.

The free plan includes 5 GB mail storage (can be upgraded at additional cost) with the standard zohomailcloud.co.uk email address.

A very important point to note is that you are not restricted to the use of the Zoho Mail desktop and phone apps, although both are very good. This specific plan DOES include IMAP/SMTP access - I know! I've added my account to my Thunderbird computer desktop and it works perfectly.

Another plus point is that you can also use 'Send mail as' for external accounts - just add the SMTP server login info for the external account.

Along with the basic email storage quota, it includes calendars (with CalDAV support), 5 GB of WorkDrive cloud storage (using the Zoho apps for desktop and mobile), and browser-based access to the Zoho Office Suite.

One final point to make clear: When signing up for the UK account, one needs to provide a UK telephone number to verify the account. Once the account has been verified and is up and running - providing that 2FA has been enabled on the account - the telephone number can be removed, which helps if wanting to set up an additional Zoho UK account.

All in all, it's a very good option for UK-based people wanting a free and reliable email account.
